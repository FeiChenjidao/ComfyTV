# 3D Retopology (Tripo)

Connect the **3D Model Stage** `model` output to this node's `model` input, choose settings, and click Run. The node uses native **Tripo: Import Model** followed by **Tripo: Retopology**. Preview, download, or connect the result to another 3D node.

- **Target faces**: `-1` is automatic; `500–20,000` triangles or `500–10,000` quads.
- **Quads**: off produces GLB; on produces FBX. The provider's file is saved unchanged to preserve quad topology.
- **Bake source textures**: enabled by default; bakes the original textures onto the new mesh.

GLB, FBX, OBJ and STL inputs are supported, including models generated by other providers. GLB with embedded textures is recommended. Convert GLTF, point clouds and splats to a supported mesh format first. Tripo limits imported models to 150 MB.

This is a **paid Tripo service** using your Comfy.org login. ComfyUI must provide `TripoImportModelNode` and `TripoRetopologyNode`; update ComfyUI if either is unavailable. No task ID or separate workflow binding is needed.
